⚙ MOTOR & ECONOMIA

Escolha de qual provedor o Jarvis "pensa". Anthropic, Perplexity e OpenAI (ChatGPT) são pagas por uso; Gemini, Groq, Mistral, Cerebras, NVIDIA NIM e OpenRouter (modelos :free) têm camada gratuita sem cartão — bom pra quem não quer colocar crédito na API.
📖 Como pegar a chave de cada provedor
Anthropic (Claude) — pago por uso
1. Crie conta em console.anthropic.com
2. Menu → API Keys → "Create Key" → copie (começa com sk-ant-...)
3. Vá em Plans & Billing e adicione um cartão + créditos (uso pessoal leve costuma custar centavos por dia)
4. Cole a chave aqui em cima
Google Gemini — grátis, sem cartão
1. Vá em aistudio.google.com e entre com sua conta Google
2. Clique em "Get API key" → "Create API key"
3. Copie e cole aqui em cima
Groq — grátis, sem cartão
1. Vá em console.groq.com e crie conta (dá pra usar login do Google)
2. Menu → API Keys → "Create API Key"
3. Copie e cole aqui em cima
OpenRouter — grátis nos modelos marcados :free
1. Vá em openrouter.ai e crie conta
2. Menu → Keys → "Create Key"
3. Copie e cole aqui em cima. Ao trocar de nível, prefira modelos com :free no nome pra não gastar nada
Mistral — grátis, sem cartão (~1 bilhão de tokens/mês)
1. Vá em console.mistral.ai e crie conta
2. Menu → API Keys → "Create new key"
3. Copie e cole aqui em cima
Cerebras — grátis, sem cartão (1M tokens/dia, super rápido)
1. Vá em cloud.cerebras.ai e crie conta
2. Menu → API Keys → "Create API Key"
3. Copie e cole aqui em cima
Perplexity — PAGO desde o primeiro request (sem camada gratuita)
1. Vá em perplexity.ai/settings/api
2. Adicione um cartão e créditos (cobra por uso, sem teste grátis)
3. Gere a chave e cole aqui em cima. Só vale a pena se quiser respostas com busca na web em tempo real — pros demais casos prefira os provedores grátis acima
NVIDIA NIM — grátis, sem cartão (1.000 créditos/mês)
1. Vá em build.nvidia.com e crie a conta gratuita de desenvolvedor
2. Abra qualquer modelo do catálogo e clique em Get API Key (a chave começa com nvapi-)
3. Copie e cole aqui em cima. Dá acesso a 100+ modelos rodando no DGX Cloud da NVIDIA
Obs: uso comercial de verdade (com clientes finais) pede licença NVIDIA AI Enterprise — pra uso pessoal, teste e desenvolvimento está liberado.
OpenAI (ChatGPT) — PAGO por uso (sem camada gratuita geral)
1. Vá em platform.openai.com e crie conta
2. Menu → API keys → "Create new secret key"
3. Adicione um cartão em Billing (contas novas ganham só um crédito único de ~$5, depois é 100% pago)
4. Copie e cole aqui em cima. Importante: sua assinatura Claude Pro/ChatGPT Plus (o app/site) NÃO dá acesso à API — são cobranças separadas
Provedor personalizado (Together, Fireworks, Ollama local...)
Preencha nome, a URL do endpoint (termina em /chat/completions) e o id do modelo na seção "Provedores personalizados" mais abaixo — a chave (se precisar) aparece aqui em cima assim que você selecionar esse provedor na lista.
